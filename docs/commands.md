## Help texts

### atc serve

```
Usage: atc serve [model] [options]

One step on a server: installs the best engine pack if needed, pulls the model if it is not installed, starts the daemon, loads the model and exposes http://127.0.0.1:1337/v1. Returns once the model answers; the daemon keeps running.

Arguments:
  [model]  owner/repo, owner/repo:file.gguf, a catalog alias, or serve.model from config

Options:
      --port <port>          API port (default: 1337)
      --host <host>          API bind address (0.0.0.0 to expose) (default: 127.0.0.1)
      --api-key <key>        Require this key on the API
      --api-key-file <path>  Read the key from a file (secrets mounts)
      --engine <provider>    llamacpp-upstream (default), llamacpp or mlx
      --ctx-size <tokens>    Context size in tokens
      --n-gpu-layers <n>     GPU layers (-1 = all)
      --embedding            Start in embedding mode

Examples:
  atc serve Qwen/Qwen3-8B-GGUF
  atc serve qwen3-8b --host 0.0.0.0 --api-key "$KEY"

Global options:
  --json                Print the result as one JSON document (errors go to stderr as JSON)
  -v, --verbose         Debug-level logging on stderr
  -q, --quiet           Only errors on stderr; no progress
  -y, --yes             Answer yes to safe confirmations; required for elevation and deletion
                        without a terminal
  --data-folder <path>  Data folder to work with (default: <system data>/atomic-chat-cli/data)
  --no-color            Disable ANSI colours (NO_COLOR is honoured too)
  -h, --help            Show help
  --version             Print the version

Status: not implemented yet in this build (exit code 3).
```

### atc run

```
Usage: atc run [model] [options]

Runs the daemon, the admin and the model in this process and stops them on SIGTERM/SIGINT. For Docker use `--init`. `--no-model` runs the daemon alone.

Arguments:
  [model]  As for serve

Options:
      --port <port>          API port (default: 1337)
      --host <host>          API bind address (0.0.0.0 to expose) (default: 127.0.0.1)
      --api-key <key>        Require this key on the API
      --api-key-file <path>  Read the key from a file (secrets mounts)
      --engine <provider>    llamacpp-upstream (default), llamacpp or mlx
      --ctx-size <tokens>    Context size in tokens
      --n-gpu-layers <n>     GPU layers (-1 = all)
      --embedding            Start in embedding mode
      --no-model             Run the daemon without loading a model
```
